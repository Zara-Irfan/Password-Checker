# Password Strength Checker

This project is a simple **Python-based Password Strength Checker** that evaluates the security level of a password based on:

* Length
* Uppercase letters
* Lowercase letters
* Digits
* Special characters

It provides a **verdict** along with **suggestions** to improve password quality.

---

## 🚀 Features

* Checks five essential password security criteria.
* Gives a clear verdict from *Very Weak* to *Very Strong*.
* Provides suggestions for missing security elements.
* Easy to run and modify.

---

## 📌 How It Works

The script calculates the password strength using a scoring method:

* **1 point** for each requirement met (total 5 points)
* Based on the total score, the script returns:

  * **Very Strong 💪** (5/5)
  * **Strong 🙂** (4/5)
  * **Medium 😐** (3/5)
  * **Weak 😕** (2/5)
  * **Very Weak** (0–1/5)

Additionally, it provides personalized suggestions if any criteria are missing.

## ▶️ How to Run

1. Make sure you have **Python 3** installed.
2. Save the code into a file (e.g., `password_checker.py`).
3. Run it
4. Enter any password when prompted.
